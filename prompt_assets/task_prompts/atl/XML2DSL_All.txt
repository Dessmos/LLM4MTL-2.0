Create a transformation module XML2DSL that maps the generic XML metamodel (`Root`, `Element`, `Attribute`, and `Text` nodes, each with `name` and `value`; elements hold `children`) to the DSL metamodel. The input is a DSL export in XML: a root element `dmd` containing a `model` element whose `name` attribute is not `Core`.

The transformation reads an attribute as an `Attribute` child of an element, and reads a tagged value as an `Element` child of that name whose own child is a `Text` node named `#text` holding the value.

Define helpers on Element: getAttrBool (attribute value equal to `true`), getAttrVal, get, getType (the `xsi:type` attribute of the child `propertyInfo`, without its first character and its last twelve), getEnumId (the `enumeration` text of `propertyInfo`), getText, getSeq (the `Element` children named `name` of the child element named `names`), hasChildren, hasAttr, isAbstract (true when the child `mdfmetadata` has attribute `classmodifier` = `abstract`), getContainment; and on the module: dslElementsById (elements named `concept`, `relationship`, or `enumeration` keyed by their `id` attribute), getSubTypes, findType.

Implement rule DomainModel for the `model` element: create a DomainModel with `name`, `identity`, `namespace`, and `isLoaded` from its attributes, classifiers from `concepts/concept` and `relationships/relationship`, and types from `enumerations/enumeration` plus four SimpleType instances named `String`, `Integer`, `Boolean`, and `Double`.

Implement rule Class for each `concept` element (attributes `id`, `name`, `identity`, `namespace`, `isLoaded`; text child `superType` holding a parent id; child `valueProperties/property`), rule Relationship for each `relationship` element (as for concept, plus `roles/role`; `isEmbedding` is true only when some `treeExpression` element whose `containmentstyle` attribute is neither `fromsource` nor `reference` names one of the relationship's role ids in its `role` text), rule Role for each `role` under `roles` (attributes `name`, `identity`, `min`, `max`, `accepts`, `isUnbounded`; text children `source` and `type` holding concept ids; `isOrdered` and `isNavigableFrom` from the `isordered` and `isnavigablefrom` attributes of its `mdfmetadata` child), rule ValueProperty for each `property` under `valueProperties` (attributes `name`, `identity`; type resolved through findType, or the enumeration named by getEnumId), rule Enumeration for each `enumeration` under `enumerations` (attributes `name`, `identity`, `namespace`; literals from `literals/enumerationLiteral`), and rule EnumerationLiteral (attributes `name`, `identity`, integer `value`), wiring superType/subTypes, roles, owner, types, and containment through these ids.
