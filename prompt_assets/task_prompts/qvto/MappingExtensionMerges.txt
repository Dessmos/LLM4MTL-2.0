Create a QVT-O transformation named **t** that takes one input model and produces one output model, both conforming to the Ecore metamodel.  
In **main**, iterate over all root EPackage elements of the input model and apply a mapping **p2p**.  
In **p2p**, create a new EPackage with the same name and map each contained EClass through **makeClass**.  
Define an abstract mapping **EClassifier::makeClassifier** that appends `1` to the current name of the result (`name := name + '1'`).  
Define **EClass::makeClass** with a `merges EClassifier::makeClassifier` clause, an **init** block that sets a temporary variable to `2`, and a body that sets the name to the source class name followed by that variable.  
A merged mapping runs after the body of the mapping that merges it, on the same result object, so the `1` is appended after the `2`: a source EClass named `A` becomes an EClass named `A21`, never `A12`.
