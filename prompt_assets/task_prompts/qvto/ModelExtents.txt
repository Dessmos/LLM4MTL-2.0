Create a QVT-O transformation named **transf** that takes one input model **m** of type *ECORE* and produces two output models **x** and **y**, also of type *ECORE*.  
In the **main** operation, instantiate two new *EPackage* objects with object literals bound to a model extent (`object EPackage@x { name := 'a' }` and `object EPackage@y { name := 'b' }`): one in **x** named `a` and one in **y** named `b`.  
Also define a mapping **EClass::toClass** that creates a corresponding *EClass* in **y**, copying the source class's name into the target. This mapping is only declared: **main** never invokes it and never reads **m**, so whatever the input model contains, **x** ends with exactly one package `a`, **y** ends with exactly one package `b`, and neither output contains an *EClass*.
