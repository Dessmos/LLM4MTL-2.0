Rename the output package to the first six characters of that output class's name (`substring(1, 6)`) followed by the output package's current name. Because every output class name starts with `mapped`, the renamed package is always `mapped` followed by the input package name: an input package `inputPkg` becomes `mappedinputPkg`.  
Define mapping **EPackage::p2p** to copy the name and map its classifiers with **EClassifier::c2c**, which produces **EClass** elements whose names are the source classifier's name prefixed with `mapped`.
