Reactions semantic test generation few-shot example.

This is format guidance only. Every identifier below is synthetic. Replace it
with runtime slots, metamodel URIs, types, and features from the deterministic
task contract. Emit no Java, Xtend, Maven files, or prose in the response.

The binding output contract is delivered separately and always applies. The
examples below only illustrate it; where an example looks like it disagrees
with the contract, the contract wins.

Note what the example does not do: neither generated file contains a root
object, and the observed model is never given content. The element the change
renames is created by the `changes` array, and its counterpart on the observed
side exists only because the transformation created it.

Note also the two value shapes. `elements` is a containment feature, so its
values build new objects. `related` is a plain reference, so its value names an
element an earlier change already created instead of building another one; a
created object value there would leave an object no container holds.
