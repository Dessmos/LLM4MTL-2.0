## Deterministic model contract (preflight)

Use this contract as ground truth. Do not infer or invent model names, metamodel URIs, XML namespaces, or type names.

| Runtime model name | Role(s) | Kind | metamodelUri | XML nsPrefix | Types used by the transformation |
|---|---|---|---|---|---|
| IN | source | emf | http://vitruv.tools/methodologisttemplate/class | class | Class, Method, Parameter |
| OUT | target | emf | http://vitruv.tools/methodologisttemplate/interface | interface | Interface, Method, Parameter |

Mandatory rules:
- In semantic_cases.json, each models[].name must equal one runtime model name above exactly.
- For EMF models, each models[].metamodelUri must equal the listed metamodelUri exactly; do not use the Ecore file stem when it differs.
- For generated EMF/XMI model files, use the listed XML nsPrefix and metamodelUri exactly in xmlns declarations.
- For plainXml models, use kind="plainXml" and omit metamodelUri.
- Do not mention or use any model/metamodel/type that is not listed in this contract.
